# Cloud Server Project

A hands-on Cloud and DevOps learning project using Ubuntu Linux.

## Features
- Nginx web server setup and management
- Custom HTML website deployment
- Server health-check Bash script
- Service and port monitoring
- Disk and memory usage checks
- Automated health checks using cron
- Logging and troubleshooting

## Tech Stack
- Ubuntu 24.04 LTS
- Nginx
- Bash scripting
- Git and GitHub
- SSH
- Cron
